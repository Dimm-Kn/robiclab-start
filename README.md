# РобикЛаб.Старт — веб-прототип

Детская программа с цифровой лабораторией: 4 занятия («Где теплее?», «Тише, совёнок спит!», «Что пропускает свет?», «Где прячется вода?»).
Работает прямо в браузере; без датчика — на встроенном симуляторе (автопилот в пульте педагога).

- **P** — скрыть/показать пульт педагога (режим показа на ТВ)
- **→ / ←** — шаги занятия, **Пробел** — действие с датчиком в симуляторе
- Прямая ссылка на шаг: `?lesson=light-1&demo=4&present`

Прототип: графика сгенерирована (Codex, Higgsfield), голоса — Higgsfield Seed Audio.
