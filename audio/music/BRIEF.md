# Музыка для «РобикЛаб.Старт» (Suno)

Детская научная программа для 5–7 лет. Музыка звучит тихо под голосами героев, поэтому:
**только инструментал (без слов и вокала)**, мягкая, без резких ударных, ровная громкость, без долгих вступлений и затуханий.
Все треки — **петли 60–90 секунд**, начало и конец в одной тональности, чтобы стык не был слышен.
Общий стиль: тёплый «мультяшный» оркестрик — ксилофон, челеста, пиццикато струнных, укулеле, лёгкие флейты. Без копирования известных мелодий.

Сохранять mp3 сюда, в `audio/music/`, с такими именами:

| Файл | Где звучит | Настроение и инструменты |
|---|---|---|
| `map.mp3` | карта «Городок Почему» | любопытное, приглашающее; ксилофон + пиццикато, 100 bpm, мажор |
| `house_heat.mp3` | Дом тепла (занятие) | уютное, «камин и какао»; челеста, мягкий бас, 85 bpm |
| `house_sound.mp3` | Башня звуков | ночная колыбельная-загадка, на цыпочках; музыкальная шкатулка, 70 bpm, очень тихо |
| `house_light.mp3` | Маяк света | морская, таинственная, но не страшная; арфа, лёгкие синтезаторные пэды, 80 bpm |
| `house_weather.mp3` | Метеостанция | солнечное летнее утро; укулеле, флейта, 95 bpm |
| `discovery.mp3` | экран «Кто прав?» | «вот это открытие!» — нарастающее радостное, 105 bpm |
| `game_heat.mp3` | игра «Согрей Робика» | бодрая, весёлая, тёплая; 115 bpm |
| `game_sound.mp3` | игра «Не разбуди совёнка» | крадущаяся пиццикато-«на цыпочках», 90 bpm, тихо |
| `game_light.mp3` | игра «Мигай, как маяк» | морское приключение, ритмичная; 110 bpm |
| `game_weather.mp3` | игра «Вырасти облако» | капельки дождя, игривая; маримба, 105 bpm |
| `lab.mp3` | режим «Лаборатория» (свободные опыты) | сосредоточенно-игривое «пробуем и смотрим»; маримба, челеста, вудблок, 92 bpm |
| `sticker.mp3` | наклейка в альбом | короткая праздничная фанфара-петля, 100 bpm |

После загрузки в приложении ничего менять не нужно: `RL.Music` (js/fx.js) сам подхватит файлы.
Выключатель — «🎶 Музыка» в пульте педагога.
